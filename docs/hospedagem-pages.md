# Página pública da política de privacidade

`docs/index.html` é a política completa (gerada por `npm run docs`). O GitHub Pages deste repositório publica a pasta `docs/`.

- Endereço da política: https://viniciuspaulinosilva.github.io/market-extension/
- Ligar o Pages: no GitHub, Settings > Pages > Source: Deploy from a branch > Branch `main` > pasta `/docs` > Save.
- Sempre que mudar `src/ui/legal.js`, rode `npm run docs`, faça commit e push; a página e a aba Config ficam iguais.
- Esse endereço é o que vai no campo "Privacy policy" do painel da Chrome Web Store.
